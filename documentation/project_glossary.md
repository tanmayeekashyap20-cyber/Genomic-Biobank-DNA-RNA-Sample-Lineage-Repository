# Project Glossary

This glossary defines important terms used in the Genomic Biobank & DNA/RNA Sample Lineage Repository.

| Term | Definition |
|---|---|
| Genomic Biobank | A repository that stores and manages biological samples and related information for research purposes. |
| Biological Sample | A collected biological material, such as blood, tissue, DNA, or RNA, maintained for research. |
| Donor | An individual from whom a biological sample is collected. |
| Consent | Documented permission from a donor for the collection, storage, and permitted use of biological samples. |
| Sample ID | A unique identifier assigned to a biological sample. |
| Sample Type | The classification of a biological sample, such as DNA, RNA, blood, or tissue. |
| Sample Lineage | The history of relationships between samples, including parent samples and samples derived from them. |
| Parent Sample | An original sample from which another sample is derived. |
| Child Sample | A sample derived from another sample through a processing or laboratory activity. |
| Sample Processing | A laboratory activity performed on a biological sample, potentially producing or modifying a sample. |
| Lineage Event | A recorded event describing an activity or occurrence in the history of a sample. |
| Storage Unit | A physical storage location or equipment used to preserve biological samples. |
| Experiment | A research activity that may involve one or more biological samples. |
| Sequencing | A laboratory process used to determine the order of nucleotides in DNA or RNA. |
| Sequencing Result | Information produced by a sequencing activity and associated with a sample. |
| Researcher | An authorized user who accesses or manages research-related information according to assigned permissions. |
| Administrator | A user responsible for administrative operations and system-level access management. |
| Lab Technician | A user role intended for laboratory-related activities, subject to the permissions configured in the application. |
| Authentication | The process of verifying a user's identity before granting access. |
| Authorization | The process of determining which actions an authenticated user is permitted to perform. |
| Role-Based Access Control (RBAC) | An access control approach in which permissions are assigned according to user roles. |
| API | Application Programming Interface; a mechanism through which application components communicate. |
| CRUD | Create, Read, Update, and Delete operations used to manage records. |
| PostgreSQL | A relational database management system used to store structured project records and relationships. |
| MongoDB | A document-oriented NoSQL database used in this project for lineage event documents. |
| Relational Database | A database that organizes information into tables connected through relationships. |
| NoSQL Database | A database approach that supports data models beyond traditional relational tables. |
| Primary Key | A column or set of columns that uniquely identifies a row in a database table. |
| Foreign Key | A database constraint that links a record to a related record in another table or the same table. |
| Data Integrity | The accuracy, consistency, and validity of stored data. |
| Audit Log | A record of selected system or database activities used for traceability. |
| JWT | JSON Web Token; a token format that can carry claims used to represent an authenticated session. |
| Hashing | A one-way transformation used to store password representations without storing the original passwords. |
| Validation | The process of checking whether submitted data meets defined rules before it is accepted. |
| ER Diagram | Entity-Relationship Diagram; a visual representation of database entities and their relationships. |
| Index | A database structure that can improve the speed of data retrieval operations. |
| Data Dictionary | Documentation describing database tables, fields, and their meanings. |

## Purpose

This glossary provides a shared vocabulary for understanding the project's database design, backend implementation, user roles, and sample lineage workflows.
