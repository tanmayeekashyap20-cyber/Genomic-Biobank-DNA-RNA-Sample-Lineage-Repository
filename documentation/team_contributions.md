# Genomic Biobank & DNA/RNA Sample Lineage Repository
# Team Contributions and Work Allocation

## 1. Introduction

This project is developed collaboratively by two team members.

The responsibilities are divided into database and backend
development, and frontend and application development.

Both members contribute to integration, documentation,
coordination, and final project delivery.

## 2. Team Member 1: Tanmayee
### Role: Database and Backend Lead

Responsibilities:

- PostgreSQL database design and development.
- Relational table creation and management.
- Primary key and foreign key relationships.
- Database constraints and integrity rules.
- SQL queries and advanced database features.
- Donor and consent APIs.
- Sample management APIs.
- Researcher management APIs.
- Laboratory process APIs.
- Sample lineage APIs.
- Storage management APIs.
- Experiment management APIs.
- Sequencing result APIs.
- MongoDB lineage event integration.
- Authentication and authorization.
- Backend API documentation.
- Database and backend documentation.

## 3. Team Member 2: Sneha
### Role: Frontend and Application Lead

Responsibilities:

- Frontend application development.
- Dashboard development.
- User interface design.
- React component development.
- Frontend forms and record management.
- Frontend integration with backend APIs.
- Login and logout interface.
- Role-aware application interface.
- Lineage graph visualization.
- Frontend documentation.
- Application screenshots and presentation materials.

## 4. Shared Responsibilities

Both team members contribute to:

- Overall system architecture.
- Backend and frontend integration.
- Database and application documentation.
- Project coordination.
- GitHub branch management.
- Code review and collaboration.
- Final project presentation.
- Submission preparation.

## 5. Conclusion

The project follows a collaborative development approach.

Tanmayee focuses on database and backend development,
while Sneha focuses on frontend and application development.

Both members contribute to integration and final delivery
of the Genomic Biobank & DNA/RNA Sample Lineage Repository.
